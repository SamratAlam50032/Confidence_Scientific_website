Order alerts (optional)

When a customer presses Place order, the order is sent to you automatically and the customer sees "Your order has been placed". Fill Telegram, Email, or both. If you leave both empty, the customer must tap Send on WhatsApp.

In Telegram open @BotFather, send /newbot, choose a name, then copy the token it gives you.
Open your new bot in Telegram, press Start and send "hi". Then press the button.
Go to web3forms.com, enter your Gmail address, and they email you an Access Key. Paste it here. Orders then arrive in that Gmail.
Open Google Maps, search your shop, press Share, Copy link, then paste it here. The website will show a View on map button.

Connect to GitHub

Publish saves your products and photos into your GitHub repository, and GitHub Pages shows them on the website. Do this once.

  1. On GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Repository access: Only select repositories, then pick your website repository.
  3. Permissions, Repository permissions, Contents: Read and write.
  4. Generate the token, copy it and paste it below.
Paste it once. If your browser asks to save the password, press Save so it fills in next time. Do not use this on a shared computer.

Your edits are kept as a draft in this browser until you publish. If you changed the data from another computer, reload the published data and drop this draft.
